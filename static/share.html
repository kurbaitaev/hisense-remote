Share with friends

Each friend controls their own TV at home. Not yours. Phone → their Roku on their Wi‑Fi.

How it works

You publish a free web page once. They open it, enter (or auto-find) their TV IP, and use the remote. No account. No your Mac.

1. Deploy the public page (you, once)

Only the web/ folder is needed. On your Mac:

cd ~/hisense-remote npx wrangler pages deploy web --project-name=roku-remote

Or push to GitHub → Cloudflare Pages / GitHub Pages with build output = web. Full steps: SHARE.md in the repo.

2. Text this to friends

Open this on your phone (same Wi‑Fi as your TV): https://kurbaitaev.github.io/hisense-remote/ 1. Allow Local Network if asked 2. On TV: Settings → System → Advanced → Control by mobile apps → Enabled 3. Connect, then use the remote (Add to Home Screen optional)

Live link from GitHub Pages for this repo.

3. Preview the friend app (this network only)

Opens the same phone→TV remote. For a real share link, deploy step 1 — this local URL only works near your Mac.

Open friend remote (local demo) Or Direct mode

What they need

  1. Roku or Hisense Roku TV
  2. Phone on the same Wi‑Fi as their TV
  3. Control by mobile apps → Enabled
