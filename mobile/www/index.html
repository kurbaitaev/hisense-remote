Find your TV

Power the TV on and keep this phone on the same Wi‑Fi.

First launch: when iOS asks for Local Network, tap Allow. If you tapped Don't Allow: iPhone Settings → Apps → Remoot → Local Network on.

If keys do nothing: on the TV open Settings → System → Advanced system settings → Control by mobile apps → Network access → Default or Enabled.

The TV's IP is in TV Settings → Network → About.
